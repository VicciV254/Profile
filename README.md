# Profile

A personal portfolio: a single web page that introduces its owner, lists skills, interests and contact details, and has a message form. It is for people who want to learn about the owner's background or work with them on data and development projects.

## View it locally

Open `index.html` in a web browser; there is nothing to install or build.

The icons and the message form need an internet connection. The form sends messages through FormSubmit, a third-party form-to-email service.
